# RB Gifting Solutions

A modern, responsive website for RB Gifting Solutions - a corporate gifting and event solutions provider.

## 🧰 Tech Stack

- **Frontend**: Next.js with TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Assets**: Images from Unsplash

## 🚀 Features

- Responsive design for all device sizes
- Animated UI elements with Framer Motion
- Advanced product filtering by categories and subcategories
- URL-based filtering for shareable product views
- Clean, modern UI with minimalist design
- Product detail pages with related product suggestions
- Contact form with validation

## 📋 Pages

- **Home**: Hero section with featured products
- **About**: Company information and services
- **Products**: Product listings with category and subcategory filtering
- **Product Details**: Detailed view of individual products with related items
- **Contact**: Contact form and company information
- **Events**: Corporate event services and solutions

## 🛠️ Setup & Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/rb-gifting.git
   cd rb-gifting
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Run the development server:
   ```
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔧 Development

- **Add new products**: Edit `data/products.ts` to add new products, categories, or subcategories.
- **Customize styles**: Modify `tailwind.config.js` and `styles/globals.css`.
- **Add new pages**: Create new files in the `pages` directory.

## 📦 Build for Production

```
npm run build
npm start
```

## 🌐 Deployment

This project is ready to be deployed on Vercel or Netlify with zero configuration.
